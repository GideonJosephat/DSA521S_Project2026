Full Name: Laban Shishiveni 225041758 Project Structure & Core Components This system compiles a Campus Service Centre Simulation using clean, structural Java implementations built without relying on standard Java Collections frameworks. Queue Management: Controls the student waiting line natively using FIFO logic (enqueue, dequeue, peek). Singly Linked List: Tracks detailed student service records dynamically (insertStudent, deleteStudent, searchStudent). Array Statistics: Processes multi-metric daily operational averages natively without utilityclass loops. Sorting Core: Runs custom operational configurations for Selection, Insertion, Merge, and Quick Sort algorithms. Stack Engine: Evaluates postfix notation separately from the primary simulation console flow. How to Run the Program
Clone or download this repository onto your machine.
Open the project inside your preferred Java IDE (such as NetBeans, IntelliJ, or Eclipse) or use a system terminal.
Ensure all source files (CampusServiceCentre.java, Student.java, StudentQueue.java, StudentLinkedList.java, etc.) are located in the same working directory.
Compile the application files: bash javac CampusServiceCentre.java
Run the core system file to interact with the console simulation menu: bash java CampusServiceCentre
